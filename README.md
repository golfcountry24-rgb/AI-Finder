# AI Finder

Каталог ШІ-сайтів на публічному API [FreeSerp](https://freeserp.ai/docs.php)
(без ключа та реєстрації; головні сторінки сайтів `index=sites`, ніша `category=ai`).

**Демо:** https://ws-58.ws.semalt.dev/
**План сайту** (мета, аудиторія, сторінки, структура): [PLAN.md](PLAN.md)

## Що зроблено

- **Три сторінки:** Каталог, Нові ШІ (стрічка за датою запуску), Про проєкт; плюс сторінка 404.
- **Пошук** по API (`q`) із затримкою 400 мс, індикатором пошуку й кнопкою очищення.
- **Фільтри** за 15 реальними категоріями ШІ з API та перемикач «Лише ШІ-продукти» (`ai_startups=1`).
- **Сортування:** релевантність, нові, старі, рейтинг домену, A → Z.
- **«Показати ще»** — посторінкове завантаження (захищене від подвійного кліку, з урахуванням межі API в 10 000).
- **Картка сайту** в модальному вікні. На мобільному вона відкривається як нижня панель.
- **Стан фільтрів в адресі** (`/?q=&cat=&sort=`, `/new?cat=`), тому посиланням можна поділитися;
  кнопка «Назад» скасовує зміну фільтра. Під час завантаження нових результатів попередні
  лишаються на екрані (приглушені), а сторінка не «стрибає».
- **Стани завантаження, помилки та порожнього результату.** Помилка показується з кнопкою «Спробувати ще», порожній результат — з кнопкою скидання фільтрів. Запит, що висить довше 15 с, завершується зрозумілою помилкою.
- **Мови:** українська та англійська з перемикачем UA/EN. Дати, числа й відмінки локалізовані.
- **Адаптивність:** 1440 / 768 / 375 px.
- **Доступність:** доступ з клавіатури та видимий фокус.
- **Анімації:** плавна поява контенту знизу вгору (Anime.js), картки з'являються під час прокрутки.
- **Лише реальні дані API.** Якщо поля немає, воно не показується; нічого не вигадано.
- **SEO:** чисті адреси (`/new`, `/about`) замість `/#/`; для кожної сторінки окремий HTML зі своїми
  `title`, `description`, `canonical`, Open Graph / Twitter-картками та JSON-LD (schema.org);
  `sitemap.xml`, `robots.txt`, OG-зображення 1200×630; справжній статус 404 для неіснуючих адрес;
  коректна ієрархія заголовків. Lighthouse: SEO 100, Accessibility 100, Best Practices 100.
- **PHP-проксі.** API надсилає некоректний CORS-заголовок, тому запити йдуть через маленький
  PHP-проксі на тому ж домені (`api/freeserp.php`). Є й альтернатива для хостингу без PHP —
  Cloudflare Worker.

- **Якість коду:** ESLint (зокрема правила React Hooks / React Compiler) і 26 юніт-тестів Vitest
  для API-шару, хука списку, форматування та i18n. Підсумок самоперевірки — [docs/REVIEW.md](docs/REVIEW.md).

**Стек:** React 19, Vite 8, React Router 7, CSS Modules, Anime.js 4; ESLint, Vitest. UI-кітів немає.

## Як запустити

Потрібен Node.js 20.19+ (або 22.12+).

```bash
npm install
npm run dev        # режим розробки, http://localhost:5173
```

Продакшн-збірка:

```bash
npm run build      # створює папку dist/
npm run preview    # перегляд збірки локально
```

Перевірки:

```bash
npm run lint       # ESLint
npm run test       # юніт-тести (Vitest)
npm run check      # lint + test + build разом
```

Публікація: завантажити **вміст** `dist/` на сервер із PHP. Для чистих адрес (`/new` → `new.html`)
потрібне правило сервера: для nginx — [deploy/nginx.conf](deploy/nginx.conf), для Apache —
`.htaccess`, який уже лежить у `dist/`. Публічна адреса для canonical і sitemap задається
змінною `VITE_SITE_URL` (див. `.env.example`). Node.js на сервері не потрібен.
Деталі (зокрема хостинг без PHP) — у [docs/TECHNICAL.md](docs/TECHNICAL.md).

## Що не встигли

- **Порівняння сайтів.** Не реалізовано режим, у якому 2–3 сайти стоять поруч за однаковими полями.
- **E2E-тести та CI.** Юніт-тести є, але браузерні сценарії (Playwright) запускалися окремо
  й у репозиторій не увійшли; GitHub Actions не налаштовано.
- **Окрема сторінка сайту.** Детальна картка відкривається лише в модальному вікні, тож
  прямого посилання на конкретний сайт немає.
- **Глибока пагінація.** API віддає не більше 10 000 результатів на один запит (`from + size ≤ 10000`),
  тому «Показати ще» має цю межу.

## Що доробили б далі

1. **Порівняння:** позначати сайти й порівнювати їх у таблиці (рейтинг, дата запуску, категорії, технології).
2. **Обране:** зберігати сайти в браузері.
3. **Маршрут для картки** (`/site/<domain>`), щоб ділитися посиланням на конкретний сайт і щоб кожен сайт мав власну сторінку для пошуковиків.
4. **Тести:** перенести e2e-сценарії Playwright у репозиторій і запускати `npm run check` у GitHub Actions.
5. **TypeScript** для моделі даних API.
6. **Темна тема.**
7. **Пререндер контенту:** зараз пошуковик бачить у статичному HTML лише мета-теги, а список сайтів — після виконання JS (Google це вміє, інші — не завжди).

## Структура

```
src/
  services/    робота з API (freeserp.js, favicon.js)
  hooks/       завантаження даних, debounce, стан у URL, утримання фільтрів у полі зору
  components/  UI-компоненти
  pages/       Explore, New AI, About, 404
  i18n/        переклади UA / EN
  motion/      анімації (Anime.js)
  seo/         мета-теги, JSON-LD, тексти для пошуковиків
  styles/      дизайн-токени
  utils/       форматування, константи (категорії, сортування)
public/api/    PHP-проксі
deploy/        конфіг nginx, Cloudflare Worker
```
